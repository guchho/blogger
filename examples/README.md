# Basic Blogger theme example

A small theme that exercises includes, local CSS, JavaScript, assets, widgets and
preview routes.

```sh
npm install
npm run dev
npm run build
```

`npm run dev` writes the production XML to `dist/template.xml` and a static
mock preview to `dist/preview/` plus route-shaped copies such as
`dist/2026/01/getting-started-with-guchho.html`.
